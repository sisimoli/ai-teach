۱۵. نکات مهم

  • تمام اندازه‌ها بر اساس mm (میلی‌متر) هستند برای سازگاری با چاپ A4
  • از grid و flexbox برای چیدمان استفاده کنید
  • تمام badgeها باید border-radius کوچک (1-2mm) داشته باشند
  • جداول باید border-collapse: collapse داشته باشند
  • رنگ‌های پس‌زمینه badgeها باید روشن و متن‌ها تیره باشند
  • از font-display برای عناوین و اعداد بزرگ استفاده کنید
  • از font-body برای متن‌های معمولی استفاده کنید
  • تمام صفحات باید dir="rtl" باشند
  • برای چاپ، از page-break-after: always بین صفحات استفاده کنید

۱۵. نکات مهم

  • تمام اندازه‌ها بر اساس mm (میلی‌متر) هستند برای سازگاری با چاپ A4
  • از grid و flexbox برای چیدمان استفاده کنید
  • تمام badgeها باید border-radius کوچک (1-2mm) داشته باشند
  • جداول باید border-collapse: collapse داشته باشند
  • رنگ‌های پس‌زمینه badgeها باید روشن و متن‌ها تیره باشند
  • از font-display برای عناوین و اعداد بزرگ استفاده کنید
  • از font-body برای متن‌های معمولی استفاده کنید
  • تمام صفحات باید dir="rtl" باشند
  • برای چاپ، از page-break-after: always بین صفحات استفاده کنید
